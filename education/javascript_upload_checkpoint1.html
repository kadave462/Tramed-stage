1. app.post("/api/upload", ...)

app is your Express server, created at the top of the file with const app = express();.

.post() is a method — a function that belongs to the server. It listens for POST requests.

GET vs POST:
— GET = "give me some data" (reading a page, loading the sales list)
— POST = "I am sending you something" (uploading a file, submitting a form)

GET /api/sales → "show me the sales list"
POST /api/upload → "here is a file, please save it"

2. upload.single("file")

This is middleware — code that runs between the request arriving and your function running. It comes from the multer library.

.single("file") means: "I expect one file, and its input name in the HTML form is file." It reads the file and puts it on req.file so your function can use it.

A delivery driver arrives. The warehouse guard (multer) checks the delivery, takes the package, and puts it on the counter (req.file). The pharmacist (your function) then picks it up and processes it.

3. async function (req, res)

— function — a block of code with a specific job
— req — short for request. Everything the browser sent: the file, the URL, headers
— res — short for response. The tool you use to send something back to the browser
— async — this function will talk to the database, which takes time. async tells JavaScript: "this function will wait for slow things without freezing everything else"

4. try {

Opens a safety net. If anything inside crashes — a bad file, a database error, anything — the crash is caught instead of breaking your whole server. We will close it later with a catch block.

Like having a supervisor watching the pharmacist work. If the pharmacist makes a mistake, the supervisor steps in and handles it — the pharmacy does not close down.

5. Checkpoint 1 — Did a file actually arrive?

if (!req.file) return res.status(400).json({ error: "No file uploaded" });

Breaking this down word by word:

— if — only run what follows IF the condition is true
— !req.file — the ! means NOT. Reads as: "if req.file does NOT exist"
— return — stop the function immediately, go no further
— res.status(400) — tell the browser: 400 = bad request, you did something wrong
— .json({ error: "No file uploaded" }) — send this message back as JSON

A delivery driver arrives at the pharmacy but the truck is empty. The pharmacist says: "There is nothing here — come back with the actual delivery."
