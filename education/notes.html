How to Build a Date Range Picker — From Scratch

A Date Range Picker is the dropdown that lets you select "Today", "Last 7 Days", or a custom start/end date. This guide covers every step: what the component is called, which file each piece goes in, and why.

What Are We Building?

A button in the navigation bar. When you click it, a dropdown appears with:

  • 6 preset buttons — Today, Yesterday, Last 7 Days, Last 30 Days, This Month, Last Month
  • 2 date inputs for a custom range — From / To
  • An Apply button for the custom range

When the user picks a range, the page reloads with the dates in the URL (e.g. ?from=2026-05-01&to=2026-05-28). The dashboard reads those dates and filters the sales data.

Files Involved

  • index.html — add the picker button and dropdown HTML inside the <nav>
  • style.css — add styles for the button, dropdown, and preset buttons
  • datepicker.js  NEW FILE — all the logic: open/close, date math, write to URL
  • dashboard.js — small change: read the URL params and filter sales by date range

Key Concepts You Will Use

position: relative / absolute The dropdown floats on top of the page. The wrapper gets position: relative (it becomes the reference point). The dropdown gets position: absolute and positions itself relative to that wrapper.
classList.toggle("open") The dropdown starts hidden. When the button is clicked, JavaScript adds the class open to the wrapper. CSS sees .dp-wrapper.open .dp-dropdown and shows it. Click again — class removed, dropdown hides again.
Date math in JavaScript new Date() gives today. d.setDate(d.getDate() - 6) moves the date 6 days backward. This is how "Last 7 Days" is calculated.
URLSearchParams + window.location.href URLSearchParams builds a query string like ?from=2026-05-01&to=2026-05-28. Setting window.location.href to a new URL reloads the page with those parameters.
window.location.search On page load, this holds the current query string. new URLSearchParams(window.location.search).get("from") extracts the value of the from parameter.

3 Link datepicker.js to the page HTML

At the bottom of index.html, just before </body>, add a second script tag after dashboard.js:

<script src="dashboard.js"></script>
<script src="datepicker.js"></script>   <!-- ADD THIS -->

Why at the bottom? The script runs when the page loads. If it ran at the top, the elements it needs (dpWrapper, dpBtn, etc.) would not exist yet — getElementById would return null. At the bottom, all elements already exist in the page.

10 Get the three elements we need JS 
const dpWrapper = document.getElementById("dpWrapper");
const dpBtn     = document.getElementById("dpBtn");
const dpLabel   = document.getElementById("dpLabel");
We store these three elements in variables so we can reuse them without calling getElementById repeatedly.

dpWrapper — we add/remove the open class on this to show/hide the dropdown.
dpBtn — we attach the click listener to this.
dpLabel — we change its text to show what is currently selected ("Today", "Last 7 Days", etc.).
11 Open and close the dropdown JS 
// Click the button → toggle the dropdown open or closed
dpBtn.addEventListener("click", function (e) {
  e.stopPropagation();
  dpWrapper.classList.toggle("open");
});

// Click anywhere outside the picker → close it
document.addEventListener("click", function (e) {
  if (!dpWrapper.contains(e.target)) {
    dpWrapper.classList.remove("open");
  }
});
classList.toggle("open") — if the class open is present, it removes it. If absent, it adds it. One line handles both directions.

e.stopPropagation() — when you click the button, the click normally also fires on the document. That would immediately trigger the "close" listener. stopPropagation stops the event from reaching the document when the button is clicked.

dpWrapper.contains(e.target) — checks whether the element you clicked is inside the wrapper. If you click on the page outside (the table, a chart), contains returns false and we close the dropdown.
12 Two helper functions JS 
// Convert a Date object to "YYYY-MM-DD" string
function toISO(date) {
  return date.toISOString().slice(0, 10);
}

// Apply a range: update label, close dropdown, reload page with URL params
function applyRange(from, to, labelText) {
  dpLabel.textContent = labelText;
  dpWrapper.classList.remove("open");
  const params = new URLSearchParams(window.location.search);
  params.set("from", from);
  params.set("to", to);
  window.location.href = "?" + params.toString();
}
toISO(date) — toISOString() gives "2026-05-28T00:00:00.000Z". .slice(0, 10) takes only the first 10 characters: "2026-05-28". This YYYY-MM-DD format is what dashboard.js uses for filtering.

applyRange(from, to, labelText) — called by every preset and by the custom Apply button. It does 4 things in order:
1. Updates the button label text
2. Closes the dropdown
3. Reads whatever is already in the URL, adds/updates from and to
4. Navigates to the new URL — the page reloads with the dates in the address bar

params.toString() — turns the URLSearchParams object into a string like from=2026-05-01&to=2026-05-28. The "?" + in front adds the question mark.
13 Preset buttons — one loop for all six JS 
document.querySelectorAll(".dp-preset").forEach(function (btn) {
  btn.addEventListener("click", function () {
    const preset = btn.dataset.preset;   // reads data-preset="today" etc.

    const today = new Date();
    today.setHours(0, 0, 0, 0);   // reset to midnight — clean date math

    if (preset === "today") {
      applyRange(toISO(today), toISO(today), "Today");

    } else if (preset === "yesterday") {
      const d = new Date(today);   // copy today first
      d.setDate(d.getDate() - 1);
      applyRange(toISO(d), toISO(d), "Yesterday");

    } else if (preset === "last7") {
      const from = new Date(today);
      from.setDate(from.getDate() - 6);
      applyRange(toISO(from), toISO(today), "Last 7 Days");

    } else if (preset === "last30") {
      const from = new Date(today);
      from.setDate(from.getDate() - 29);
      applyRange(toISO(from), toISO(today), "Last 30 Days");

    } else if (preset === "thismonth") {
      const from = new Date(today.getFullYear(), today.getMonth(), 1);
      const to   = new Date(today.getFullYear(), today.getMonth() + 1, 0);
      applyRange(toISO(from), toISO(to), "This Month");

    } else if (preset === "lastmonth") {
      const from = new Date(today.getFullYear(), today.getMonth() - 1, 1);
      const to   = new Date(today.getFullYear(), today.getMonth(), 0);
      applyRange(toISO(from), toISO(to), "Last Month");
    }
  });
});
querySelectorAll(".dp-preset") — returns all 6 preset buttons as a list.
.forEach(...) — runs the function once per button, attaching a click listener to each one. One loop instead of 6 separate addEventListener calls.

btn.dataset.preset — reads the data-preset="yesterday" HTML attribute. JavaScript can read any data-* attribute via .dataset.attributeName.

new Date(today) — creates a COPY of today. You must copy before calling setDate, otherwise you modify the original today variable and the next preset that uses it gets the wrong date.

setDate(getDate() - 6) — moves the date 6 days back. Today + 6 previous days = 7 total days.

new Date(year, month, 1) — first day of a month. Month numbers are 0-indexed: January = 0, December = 11.
new Date(year, month, 0) — day 0 of any month = the last day of the previous month. new Date(2026, 5, 0) = May 31. This gives you the last day without hard-coding 28/29/30/31.
14 Custom range — Apply button JS 
document.getElementById("dpApply").addEventListener("click", function () {
  const from = document.getElementById("dpFrom").value;
  const to   = document.getElementById("dpTo").value;

  if (!from || !to) {
    alert("Please select both a From and a To date.");
    return;
  }
  if (from > to) {
    alert("The From date cannot be after the To date.");
    return;
  }

  const label = from === to ? from : from + " → " + to;
  applyRange(from, to, label);
});
.value on a date input — the browser always gives the value as "YYYY-MM-DD". No conversion needed — it is already in the same format as toISO().

if (!from || !to) — an empty date input has the value "", which is falsy. ! turns falsy into true. So this line reads: "if from is empty OR to is empty".

from > to — string comparison works on ISO dates because Year comes first, then Month, then Day. "2026-05-28" is greater than "2026-05-01".

from === to ? from : from + " → " + to — if both dates are the same day, just show the date. If they are different, show "2026-05-01 → 2026-05-07". The ? is a ternary operator: condition ? value-if-true : value-if-false.
15 On page load — restore the label from the URL JS 
// After the page reloads, restore the label to show what range is selected
const currentParams = new URLSearchParams(window.location.search);
const currentFrom   = currentParams.get("from");
const currentTo     = currentParams.get("to");

if (currentFrom && currentTo) {
  dpLabel.textContent = currentFrom === currentTo
    ? currentFrom
    : currentFrom + " → " + currentTo;
}
After the page reloads with ?from=2026-05-01&to=2026-05-07 in the URL, the button label would reset to "Today". This code runs immediately when the script loads and restores the label to match what is in the URL.

window.location.search — the part of the URL after the ?. If the URL is index.html?from=2026-05-01&to=2026-05-07 this gives ?from=2026-05-01&to=2026-05-07.

params.get("from") — returns the value of the from key as a string, or null if it does not exist in the URL.

Part 4 — dashboard.js  small change

17 Read URL params and filter sales by date range JS

In dashboard.js, find the block that calculates latestDate and todaySales. Replace it with this:

// Read date range from URL — e.g. ?from=2026-05-01&to=2026-05-07
const urlParams  = new URLSearchParams(window.location.search);
const filterFrom = urlParams.get("from");
const filterTo   = urlParams.get("to");

// Fall back to the most recent date in the data if no URL params exist
const latestDate = sales
  .map((s) => s.date.slice(0, 10))
  .sort()
  .at(-1);

const todaySales = sales.filter(function (sale) {
  const d = sale.date.slice(0, 10);
  if (filterFrom && filterTo) {
    return d >= filterFrom && d <= filterTo;
  }
  return d === latestDate;
});
filterFrom / filterTo — will be strings like "2026-05-01" if the user selected a range, or null if they opened the page directly with no URL params.

d >= filterFrom && d <= filterTo — ISO date string comparison. "2026-05-15" >= "2026-05-01" is true. No need to create Date objects just to compare dates in this format.

Fallback to latestDate — if no URL params exist (first page visit, no picker used), the dashboard defaults to the most recent date in the data. The picker does not break existing behavior.
