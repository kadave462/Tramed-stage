Phase 7 — JavaScript (connecting to the server)

12Script tag — where to place it JS 
<!-- Place this just before </body> -->
<script>
  // all JavaScript goes here
</script>
Why at the bottom: The browser reads HTML top to bottom. If the script runs before the HTML elements exist, getElementById returns null and nothing works. At the bottom, all elements are already created.
13Fetch data from the server JS 
async function loadDashboard() {
  const salesRes = await fetch('/api/sales');
  const sales    = await salesRes.json();

  const stockRes = await fetch('/api/stock');
  const stock    = await stockRes.json();

  // sales and stock are now arrays of objects
  console.log(sales[0]);  // check DevTools to see the shape
}

loadDashboard();
async / await: Fetching from the server takes time. async marks the function as "this will wait". await pauses until the server replies. Without it you'd use the data before it arrives.

fetch('/api/sales'): Sends a GET request to your Express server. The server queries the database and sends back JSON. .json() turns that text into a real JavaScript array.

Phase 8 — Building dashboard.js (Complete Step-by-Step)

This is the file that brings the dashboard to life. It fetches real data from the server and puts numbers into the HTML elements you built in Phase 3.

ACreate the file and link it to index.html JS

Create a new file called dashboard.js in the public/ folder. Then in index.html, just before </body>, add this line:

<script src="dashboard.js"></script>
Why a separate file? Keeps HTML clean. The same dashboard.js can be reused and tested on its own. In index.html, the script tag must be at the bottom — after all the HTML elements — so that when JavaScript runs, all the elements it needs (kpiRevenue, etc.) already exist in the page.
BCreate the async function shell JS 
async function loadDashboard() {
  // all code goes inside here
}

loadDashboard();
async function: This function fetches data from the server, which takes time. async tells JavaScript "this function can pause and wait." Without it, await won't work.

loadDashboard(); at the bottom is what actually RUNS the function. Defining a function alone does nothing — you must call it. Think of it as: the lines above write the recipe, this line says "now cook it."
CFetch sales and stock data from the server JS 
async function loadDashboard() {
  const sales = await (await fetch("/api/sales")).json();
  const stock = await (await fetch("/api/stock")).json();
}
fetch("/api/sales") sends a request to your Express server at that URL. The server queries the database and sends back a JSON text response.

await pauses execution until the server replies — like waiting for a phone call to connect before you speak.

.json() converts the text response into a real JavaScript array of objects.

After these two lines, sales is an array like:
[{ invoiceId: 218815, productName: "Paracetamol", totalAmount: 5000, ... }, ...]
DCreate empty buckets to hold totals JS 
async function loadDashboard() {
  const sales = await (await fetch("/api/sales")).json();
  const stock = await (await fetch("/api/stock")).json();

  let totalRevenue = 0;
  let totalCost = 0;
}
let creates a variable that can change (unlike const which is fixed).

We start both at 0 because we are going to add to them in a loop. Think of it like putting an empty glass on the table before you pour water into it — you need the glass first.
ELoop through every sale and add up the numbers JS 
  for (const sale of sales) {
    totalRevenue += sale.totalAmount ?? 0;
    totalCost    += (sale.costPrice ?? 0) * (sale.quantity ?? 0);
  }
for (const sale of sales) runs the block of code once for every row in the sales array. Each time, sale is the current row.

+= means "add this to what is already there." So if totalRevenue is 5000 and sale.totalAmount is 2000, it becomes 7000.

?? 0 means "if this value is null or missing, use 0 instead." This protects against rows with empty fields crashing the calculation.
FCalculate gross profit and count unique invoices JS 
  const grossProfit = totalRevenue - totalCost;

  const invoiceIds = new Set(sales.map(s => s.invoiceId));
  // invoiceIds.size = number of unique invoices
grossProfit is simple subtraction — revenue minus cost.

sales.map(s => s.invoiceId) creates a new array of only the invoiceId from every row — like pulling one column from a spreadsheet.

new Set(...) removes all duplicates. If invoice 218815 appears 5 times (once per product), the Set only keeps it once.

.size gives the count of unique items in the Set — that is the real invoice count.
GCreate a number formatter function JS 
  function fmt(n) {
    return Math.round(n).toLocaleString("fr-RW");
  }
Math.round(n) removes decimal places (1234567.8 → 1234568).

.toLocaleString("fr-RW") formats the number for French/Rwanda: adds spaces as thousand separators. So 1234567 becomes "1 234 567" — much easier to read on a dashboard.

We write it as a function so we can reuse it for Revenue, Cost, Profit — type fmt(...) instead of repeating the same code 5 times.
HPut the numbers into the KPI cards JS 
  document.getElementById("kpiRevenue").textContent  = fmt(totalRevenue);
  document.getElementById("kpiCost").textContent     = fmt(totalCost);
  document.getElementById("kpiProfit").textContent   = fmt(grossProfit);
  document.getElementById("kpiInvoices").textContent = invoiceIds.size;
  document.getElementById("kpiItems").textContent    = sales.length + " line items";
document.getElementById("kpiRevenue") finds the HTML element with id="kpiRevenue". This is the connection between JavaScript and HTML — the id in HTML must match exactly what you type here.

.textContent = ... replaces whatever text is inside that element. The "—" placeholder you typed in HTML disappears and the real number appears instead.

This is the moment the dashboard "wakes up" — 5 lines, 5 KPI cards filled.
IBuild the Top Products bar chart JS 
  // Step 1: add up revenue per product
  const revenueByProduct = {};
  for (const sale of sales) {
    const name = sale.productName;
    revenueByProduct[name] = (revenueByProduct[name] || 0) + sale.totalAmount;
  }

  // Step 2: sort from highest to lowest, keep top 10
  const sorted = Object.entries(revenueByProduct)
    .sort((a, b) => b[1] - a[1])
    .slice(0, 10);

  const labels = sorted.map(x => x[0]);  // product names
  const values = sorted.map(x => x[1]);  // revenue amounts

  // Step 3: draw the chart
  new Chart(document.getElementById("chartTopProducts"), {
    type: "bar",
    data: {
      labels: labels,
      datasets: [{ label: "Revenue (RWF)", data: values, backgroundColor: "#1a7a4a" }]
    },
    options: { indexAxis: "y", plugins: { legend: { display: false } } }
  });
revenueByProduct is an object used as a dictionary: key = product name, value = total revenue. We loop through all sales and add up the totalAmount per product name.

Object.entries(...) converts the dictionary into an array of pairs so we can sort it.

.sort((a, b) => b[1] - a[1]) sorts from highest to lowest by value.

.slice(0, 10) keeps only the first 10 items.

indexAxis: "y" makes the bars go horizontal — easier to read long product names.
JBuild the Sales by Hour chart JS 
  // Count sales per hour
  const byHour = Array(24).fill(0);  // [0,0,0,...] — 24 slots, one per hour
  for (const sale of sales) {

    byHour[hour] += sale.totalAmount ?? 0;

Array(24).fill(0) creates an array of 24 zeros — one slot for each hour of the day (0 through 23).

new Date(sale.date).getHours() extracts just the hour number from a date — for example "2026-05-25T14:32:00" gives 14.

byHour[hour] += ... adds the sale amount to the correct hour slot.

async function loadDashboard() {
  const sales = await (await fetch("/api/sales")).json();
  const stock = await (await fetch("/api/stock")).json();

  // ── Totals ────────────────────────────────────────────────
  let totalRevenue = 0;
  let totalCost    = 0;
  for (const sale of sales) {
    totalRevenue += sale.totalAmount ?? 0;
    totalCost    += (sale.costPrice ?? 0) * (sale.quantity ?? 0);
  }

  const grossProfit = totalRevenue - totalCost;
  const invoiceIds  = new Set(sales.map(s => s.invoiceId));

  function fmt(n) { return Math.round(n).toLocaleString("fr-RW"); }

  // ── KPI cards ─────────────────────────────────────────────
  document.getElementById("kpiRevenue").textContent  = fmt(totalRevenue);
  document.getElementById("kpiCost").textContent     = fmt(totalCost);
  document.getElementById("kpiProfit").textContent   = fmt(grossProfit);
  document.getElementById("kpiInvoices").textContent = invoiceIds.size;
  document.getElementById("kpiItems").textContent    = sales.length + " line items";

  // ── Top Products chart ────────────────────────────────────
  const revenueByProduct = {};
  for (const sale of sales) {
    const name = sale.productName;
    revenueByProduct[name] = (revenueByProduct[name] || 0) + sale.totalAmount;
  }
  const sorted = Object.entries(revenueByProduct).sort((a, b) => b[1] - a[1]).slice(0, 10);
  new Chart(document.getElementById("chartTopProducts"), {
    type: "bar",
    data: { labels: sorted.map(x => x[0]), datasets: [{ label: "Revenue (RWF)", data: sorted.map(x => x[1]), backgroundColor: "#1a7a4a" }] },
    options: { indexAxis: "y", plugins: { legend: { display: false } } }
  });

  // ── Sales by Hour chart ───────────────────────────────────
  const byHour = Array(24).fill(0);
  for (const sale of sales) {
    byHour[new Date(sale.date).getHours()] += sale.totalAmount ?? 0;
  }
  new Chart(document.getElementById("chartHourly"), {
    type: "bar",
    data: { labels: byHour.map((_, i) => i + "h"), datasets: [{ label: "Revenue", data: byHour, backgroundColor: "#f0a500" }] },
    options: { plugins: { legend: { display: false } } }
  });

  // ── Transaction table ─────────────────────────────────────
  const tbody = document.getElementById("txnBody");
  for (const sale of sales) {
    const cost   = (sale.costPrice ?? 0) * (sale.quantity ?? 0);
    const margin = sale.totalAmount > 0 ? (((sale.totalAmount - cost) / sale.totalAmount) * 100).toFixed(1) : "0.0";
    const tr = document.createElement("tr");
    tr.innerHTML = `<td>${sale.invoiceId}</td><td>${new Date(sale.date).toLocaleDateString()}</td><td>${sale.productName}</td><td>${sale.quantity}</td><td>${fmt(sale.unitPrice)}</td><td>${fmt(sale.totalAmount)}</td><td>${fmt(cost)}</td><td>${margin}%</td>`;
    tbody.appendChild(tr);
  }
  document.getElementById("txnCount").textContent = sales.length;

  // ── Stock alerts ──────────────────────────────────────────
  const alertContainer = document.getElementById("stockAlerts");
  const lowStock = stock.filter(item => item.qtyLive < 10);
  if (lowStock.length === 0) {
    alertContainer.innerHTML = "<p style='color:#198754;'>All stock levels OK</p>";
  } else {
    for (const item of lowStock) {
      const div = document.createElement("div");
      div.innerHTML = `<div style="display:flex;justify-content:space-between;padding:8px 0;border-bottom:1px solid #f0f0f0;"><div style="font-weight:500;">${item.productName}</div><div style="color:#dc3545;font-weight:600;">${item.qtyLive} left</div></div>`;
      alertContainer.appendChild(div);
    }
  }
}
